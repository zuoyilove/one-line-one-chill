# One Line, One Chill

One line of horror for the [make.fun](https://make.fun) bounty
[One Line, One Chill](https://make.fun/bounty/u-azazex-one-line-one-chill-6d4d5488).

- **Owner:** zuoyilove
- **Repo:** one-line-one-chill
- **Description:** A single sentence of horror, under 200 characters, written by a small Python program to `/output/entry.txt` — no input, no network, no randomness, so every run produces the same line.
- **Run:** `python3 main.py` (writes `/output/entry.txt`)
- **Referral code:** dcz81z7d

## The line

> The dentist found a second row of teeth growing behind mine, small and patient, already practising my smile.

108 characters, one sentence. The scare is earned body horror with a concrete image (a second row of teeth) and a closing twist (they are practising *my* smile), rather than gore or a named monster.
